# Adventure brig — character study

A standalone Blender variation of the integrated-cabin design. No Unity implementation.

- Fuller hull shoulders and a more upturned, forward-swept bow.
- Larger stern lanterns and chunkier arched window frames.
- Coral curling-wave emblem following the curved aft mainsail, with a small brass wave carving on either bow shoulder.
- Longer pennant, one broad stitched canvas repair, a restrained canvas roll and coiled working rope.
- Solid entrance beam and capped curve ends finish the quarterdeck trim.

The cabin/hull shared-edge validation remains in the generator. Prior variants remain intact for comparison. This is a visual prototype; production rigging, gunport openings, hydrostatics and performance remain unvalidated.

Source: `tools/blender/adventure_brig_study_v4.py`. Blender model: `tools/blender/source/adventure-brig-design-v4.blend`. The three images are renders from that model, not generated concept paintings.
