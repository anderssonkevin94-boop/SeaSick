# Adventure brig — second design pass

Standalone Blender design revision. No Unity export or implementation.

Changes from the initial study:
- Smoothly interpolated hull shoulders, a forward-raked bow and stronger rising sheer at bow and stern.
- Cabin tumblehome (narrower upper walls), raked stern, rounder quarterdeck corners and thicker window frames. Construction is deformed together to keep trim aligned.
- Fuller curved canvas, subtly uneven feet and differentiated course/topsail proportions; mast platforms reduced and moved aft to clear the canvas.
- Warmer timber, brighter ivory canvas and a stronger key light.

The original study remains available for comparison. V2 source is `tools/blender/adventure_brig_study_v2.py`; model is `tools/blender/source/adventure-brig-design-v2.blend`. Front and back renders use slight three-quarter angles; side is the profile.

This is an unapproved visual prototype. Hydrostatics, resource/upgrade attachments, production topology and runtime performance have not been validated. Gunports are still presentation geometry rather than finished hull openings; the next detail pass should address those once the main design is approved.
