# Adventure brig — standalone design review

A new Blender concept based on the approved illustrated brig: honey timber, teal topsides, coral gunport trim, cream canvas and a compact raised stern. This is a design study, not an integrated or buoyancy-validated game asset.

- Source: `tools/blender/adventure_brig_study.py`, executed with Blender MCP.
- Model: `tools/blender/source/adventure-brig-design.blend` (isolated scene).
- Views: `brig-front.png`, `brig-back.png`, `brig-side.png`. Front and back use a slight three-quarter angle to reveal depth; side shows the profile.
- Coordinate system: bow +X, beam ±Y, up +Z. Hull approximately 25 m long and 7.8 m wide, excluding the bowsprit and projecting trim.
- Hull, sails, gunport lids, cannon barrels, cabin details and fittings are separate editable objects. Fine detailing is intentionally object-heavy for this review; it requires consolidation and rigging before production.

No files under Unity's Assets directory are created or edited by this study. No export, prefab replacement, scene integration or gameplay change is authorized until design approval.
