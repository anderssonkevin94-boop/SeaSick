SEASICK / ART DIRECTION / FLEET V1

Every upgrade earns its character.

Twenty ship studies, from a working skiff to the 24-cannon Sea Crown. The progression adds shelter, cabins, batteries, balconies, galleries and gilded carving. Several upgrades retain the same hull size.
