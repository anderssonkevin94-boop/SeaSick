# First crew example — deckhand

Standalone Blender MCP design study, approximately 1.9 m tall in ship model units. Broad shoulders, enlarged head and hands, coral headcloth/scarf, cream rolled sleeves and teal vest prioritise readability against the ship's timber. Separate editable parts; not rigged or production topology.

`sailor-portrait.png` shows the design close up. `sailor-on-deck.png` is a Blender scale illustration aboard the V8 ship, not a capture from the game or an exact gameplay camera match.
