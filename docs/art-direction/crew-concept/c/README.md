# Option C — expressive deckhand

Blender-only art concept following the selected approximately 3½-head proportions. Larger head and mitten hands, shorter legs, broader torso. Coral headcloth and scarf, cream shirt, teal vest and dark boots preserve a readable palette at small sizes.

Character cues: uneven brows, crooked smile, broad nose, loose forelock, slight head tilt and one hand resting at the belt. Forearms and hands are merged sculpt volumes. Separate clothing meshes remain a concept construction, not production animation topology. No rig or Unity integration.

`sailor-on-deck.png` illustrates relative scale aboard the V8 brig in Blender; it does not represent the exact Unity gameplay camera.
