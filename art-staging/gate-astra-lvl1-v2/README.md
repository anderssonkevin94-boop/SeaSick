# Gate V2

Matching gate revision for Palisade Kit V2. Use ../palisade-astra-lvl1-v2/README.md for the complete placement, axis, articulation and integration contract. That folder includes copies of both gate FBXs for a single handoff.

Gate_L1.fbx: fixed 3m span, square capped posts, two hinged leaves, 2708 triangles.
Gate_Breached_3m.fbx: the same standing posts only, 264 triangles.
Both root pivots are at the start end on ground, Blender +X along the wall, +Z up. They are not compatible with V1's centered root without adapting placement.

Saved Blender: ../../tools/blender/source/gate-astra-lvl1-v2.blend
Generator: ../../tools/blender/gate_astra_lvl1_v2.py

FBX round trips and sampled hinge sweeps passed. No Unity import or gameplay changes performed.
