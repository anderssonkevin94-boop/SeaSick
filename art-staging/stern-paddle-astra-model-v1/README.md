# Stern Paddle Astra Model V1

Validation renders from `tools/blender/stern_paddle_astra_v1.py`.

The acceptance geometry is visible in:

- `renders/steamer_plan.png` - flat transom and aft-mounted cassette.
- `renders/steamer_astern.png` - rail rises over the wheel only in Z.
- `renders/steamer_stern34.png` - modular stern assembly and open deck.
- `renders/steamer_profile.png` - wheel fully aft of the hull.

The generator also produces bow, chase, and underbody debug views.
