# Building Art Direction

- Create and review assets in art-staging; do not import into the game without approval.
- Every completed asset includes a README covering the preferred export/version, scale, materials, modules, states, markers, and unfinished integration work.
- Campfire flame effects are external VFX, not solid flame meshes. Fuel storage has independently removable stock meshes.
- All first-tier buildings with roofs use tarp/canvas roofs. No shingles, tiles, or thatch at this tier.
- Use the approved level-one sawmill as the material, scale, and flat-shaded style reference.
- Keep each building's plot fixed across upgrades.
- Production assets have visible input storage, a work station, and visible output storage.
- Inventory slots and work states are independent meshes, not permanent decorative stock.
- First-tier quarry: manual stonecutting yard with canvas lean-to, masonry tool wall, lifting jib, rough-stone bay, and brick pallet.
