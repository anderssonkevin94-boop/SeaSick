# SeaSick

A 3D game built with Unity 6 (6000.4.3f1) and the Universal Render Pipeline.

- Design doc: [docs/GDD.md](docs/GDD.md)
- AI/contributor conventions: [CLAUDE.md](CLAUDE.md)

## Setup
1. Install Unity 6000.4.3f1 via Unity Hub
2. Clone with LFS: `git lfs install && git clone <repo-url>`
3. Open the project folder in Unity Hub
